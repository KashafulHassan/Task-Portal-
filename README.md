# 📋 InternFlow — Internship Task Management Portal

A lightweight, responsive web application built for interns to track assignments, organize daily priorities, and update task execution statuses seamlessly.

---

## 🚀 Live Demo

🔗 **[View Live Application](https://kashafulhassan.github.io/Task-Portal-/)**

---

## ✨ Key Features

* **Responsive Layout:** Optimized for desktop monitors, tablets, and mobile screens.
* **Task Overview & Details:** Displays core task metadata including Title, Description, Priority (`Low`, `Medium`, `High`), Deadline date, and Status (`Pending`, `In Progress`, `Completed`).
* **Dynamic Filtering:** Filter tasks instantly across both status and priority levels to isolate urgent items.
* **Status Updates:** Update task statuses directly through interactive controls.
* **Form & Input Validation:** Built-in validation prevents empty submissions, ensures logical deadline selections, and provides visual cues for missing fields.
* **State Persistence:** Uses browser local storage / state handling so task changes remain intact across page reloads.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic document structure (forms, sections, status badges).
* **CSS3:** Custom layout system utilizing Flexbox and Grid, CSS variables for design consistency, and media queries for device adaptation.
* **JavaScript (ES6+):** Dynamic DOM manipulation, filtering logic, event handling, and data binding.
